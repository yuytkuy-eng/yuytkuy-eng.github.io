# Template provenance

Based on https://github.com/academicpages/academicpages.github.io (master archive downloaded 2026-10-04).
The original MIT LICENSE is retained. AcademicPages derives from Minimal Mistakes.

Personalized configuration, content pages, author sidebar, navigation, and an additional SCSS layer.
The Jekyll engine, layouts, Sass base, local icons, and publication collection are retained.
The Gemfile uses Jekyll 4.4 directly, with GitHub Actions to build and deploy instead of the github-pages gem.
Unused demonstration content and upstream maintenance workflows were removed from this personal copy.
