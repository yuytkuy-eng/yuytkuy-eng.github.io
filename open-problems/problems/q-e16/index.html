Problem

Does there exist a finite-dimensional bipartite entangled state with zero distillable secret key?[1]

Definitions

Bipartite states and entanglement

Let dA,dB≥2d_A,d_B\ge 2dA​,dB​≥2 be integers, and set A=CdAA=\mathbb C^{d_A}A=CdA​ and B=CdBB=\mathbb C^{d_B}B=CdB​. For a finite-dimensional Hilbert space HHH, let L(H)\mathcal L(H)L(H) denote its linear operators and define the density operators by

D(H)={ρ∈L(H):ρ⪰0, Tr⁡ρ=1}.\mathcal D(H)=\{\rho\in\mathcal L(H):\rho\succeq0,\ \operatorname{Tr}\rho=1\}.D(H)={ρ∈L(H):ρ⪰0, Trρ=1}.

The separable states are the finite convex combinations of product states:

Sep⁡(A:B)={∑j=1rpjαAj⊗βBj: r∈N,pj≥0, ∑jpj=1,αAj∈D(A), βBj∈D(B)}.\begin{aligned}\operatorname{Sep}(A:B)=\Big\{&\sum_{j=1}^{r}p_j\alpha_A^j\otimes\beta_B^j:\ r\in\mathbb N,\\&p_j\ge0,\ \sum_jp_j=1,\\&\alpha_A^j\in\mathcal D(A),\ \beta_B^j\in\mathcal D(B)\Big\}.\end{aligned}Sep(A:B)={​j=1∑r​pj​αAj​⊗βBj​: r∈N,pj​≥0, j∑​pj​=1,αAj​∈D(A), βBj​∈D(B)}.​

A state ρAB∈D(A⊗B)\rho_{AB}\in\mathcal D(A\otimes B)ρAB​∈D(A⊗B) is entangled if ρAB∉Sep⁡(A:B)\rho_{AB}\notin\operatorname{Sep}(A:B)ρAB​∈/Sep(A:B).

Protocols and ideal keys

Let ψABE=∣ψ⟩ ⁣⟨ψ∣\psi_{ABE}=|\psi\rangle\!\langle\psi|ψABE​=∣ψ⟩⟨ψ∣ purify ρAB\rho_{AB}ρAB​, so Tr⁡EψABE=ρAB\operatorname{Tr}_E\psi_{ABE}=\rho_{AB}TrE​ψABE​=ρAB​; Eve holds EEE. An nnn-copy protocol Λn\Lambda_nΛn​ applies local quantum operations and authenticated public classical communication (LOPC) to ψABE⊗n\psi_{ABE}^{\otimes n}ψABE⊗n​. Eve's final system En′=E⊗nTnE'_n=E^{\otimes n}T_nEn′​=E⊗nTn​ includes the entire public transcript TnT_nTn​.

A protocol consists of a finite sequence of local quantum instruments and public messages, adapted to earlier outcomes. Each instrument comprises completely positive, trace-nonincreasing maps whose sum is trace-preserving.

The protocol outputs classical registers KA,KBK_A,K_BKA​,KB​ with values in [mn]={1,…,mn}[m_n]=\{1,\ldots,m_n\}[mn​]={1,…,mn​}. Write their joint state with Eve as ωnKAKBEn′\omega_n^{K_AK_BE'_n}ωnKA​KB​En′​​. An ideal key is uniform, shared by both parties, and independent of Eve:

τn=1mn∑j=1mn∣jj⟩ ⁣⟨jj∣KAKB⊗σEn′.\tau_n=\frac1{m_n}\sum_{j=1}^{m_n}|jj\rangle\!\langle jj|_{K_AK_B}\otimes\sigma_{E'_n}.τn​=mn​1​j=1∑mn​​∣jj⟩⟨jj∣KA​KB​​⊗σEn′​​.

Here σEn′\sigma_{E'_n}σEn′​​ is a density operator on Eve's system. Define the key error by

en=12∥ωn−τn∥1,∥X∥1=Tr⁡X†X.e_n=\tfrac12\|\omega_n-\tau_n\|_1,\qquad\|X\|_1=\operatorname{Tr}\sqrt{X^\dagger X}.en​=21​∥ωn​−τn​∥1​,∥X∥1​=TrX†X​.

Distillable secret key

The optimal asymptotic number of secret bits per input copy is

KD(ρAB)=sup⁡{R≥0: ∃(Λn,mn,σEn′)n≥1,en⟶0,lim inf⁡n→∞log⁡2mnn≥R}.\begin{aligned}K_D(\rho_{AB})=\sup\Big\{R\ge0:\ &\exists(\Lambda_n,m_n,\sigma_{E'_n})_{n\ge1},\\&e_n\longrightarrow0,\\&\liminf_{n\to\infty}\frac{\log_2m_n}{n}\ge R\Big\}.\end{aligned}KD​(ρAB​)=sup{R≥0: ​∃(Λn​,mn​,σEn′​​)n≥1​,en​⟶0,n→∞liminf​nlog2​mn​​≥R}.​

Assumptions

The local dimensions are fixed. The only initial shared resource is ρAB⊗n\rho_{AB}^{\otimes n}ρAB⊗n​. Local ancillas, local randomness, and authenticated two-way public communication are allowed. The number of rounds and computational cost are unrestricted.

Claim

∃dA,dB∈N,dA,dB≥2,∃ρAB∈D(CdA⊗CdB),ρAB∉Sep⁡(A:B)∧KD(ρAB)=0  ?\begin{gathered}\exists d_A,d_B\in\mathbb N,\quad d_A,d_B\ge2,\\\exists\rho_{AB}\in\mathcal D(\mathbb C^{d_A}\otimes\mathbb C^{d_B}),\\\rho_{AB}\notin\operatorname{Sep}(A:B)\quad\land\quad K_D(\rho_{AB})=0\;?\end{gathered}∃dA​,dB​∈N,dA​,dB​≥2,∃ρAB​∈D(CdA​⊗CdB​),ρAB​∈/Sep(A:B)∧KD​(ρAB​)=0?​

Progress

  • Horodecki et al. constructed PPT bound entangled states with distillable entanglement ED(ρ)=0E_D(\rho)=0ED​(ρ)=0 and distillable secret key KD(ρ)>0K_D(\rho)>0KD​(ρ)>0 (2005).[2]
  • LOPC key distillation and LOCC distillation of private states are asymptotically equivalent (2009).[1, §§VIII–IX]
  • Horodecki, Sikorski, Das, and Wilde studied secret key cost and the irreversibility of privacy resources (2026). Some results assume that every entangled state has positive distillable key; §1 lists this question as open.[3]
