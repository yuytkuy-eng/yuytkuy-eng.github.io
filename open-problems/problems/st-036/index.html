The minimum Kochen–Specker set in dimension three

UNSOLVED
Fields
Quantum foundations and combinatorial geometry
Topics
Kochen–Speckercontextualityorthogonality graphSATexact geometry

Problem

Definitions

A real projective ray set is Kochen–Specker if it admits no zero–one coloring assigning exactly one one to each orthonormal triple and respecting orthogonal pairs.

Assumptions

The real three-dimensional ray model.

Claim

Determine the minimum cardinality, currently bounded by 24≤m≤3124\le m\le3124≤m≤31; consider the complex model separately.
