The continuum TDDFT density–potential map beyond time-analytic potentials

UNSOLVED
Fields
Time-dependent density functional theory
Topics
TDDFTdensity-potential mappingRunge-Gross theoremnonanalytic time dependenceCoulomb systems

Problem

Assumptions

Continuum three-dimensional time-dependent potentials with well-posed evolution and fixed initial state, without time analyticity.

Claim

Fix a finite-energy N-electron initial state Ψ_0 for the Coulomb interaction. For scalar potentials v(t) in an explicit non-time-analytic class, for example L^1([0,T];L^{3/2}+L^∞) with additional spatial Sobolev regularity, prove that two potentials producing the same density n(r,t) differ only by a function of time. In the same class, characterize a nonempty set of admissible densities for which a representing potential exists locally in time.
