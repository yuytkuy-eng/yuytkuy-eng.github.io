Fault tolerance with budgeted correlated noise

UNSOLVED
Fields
Quantum ComputingComputational Complexity
Topics
complexity

Problem

Definitions

Use uniform polynomial-size circuits and input bit length as the complexity parameter. BQP has no witness; QMA has a polynomial-qubit witness; QCMA has a polynomial-bit witness; QMA(2) has two unentangled quantum witnesses. Standard bounded-error verification has completeness at least 2/32/32/3 and soundness at most 1/31/31/3.

Noise is a specified CPTP model or adversarial error budget; fix logical circuit size and target failure probability.

Assumptions

A two- or three-dimensional local architecture, local dimension, per-step error rates, correlation decay and decoder class.

Claim

For explicitly budgeted spatially/temporally correlated or adversarial noise, establish fault-tolerance thresholds and space-time overhead bounds for two- or three-dimensional local architectures. Specify local dimension, strength/correlation or per-step corruption budget, logical width and depth, total failure probability ε\varepsilonε, and classical decoding time; aim for qubit implementations with useful constants.

Progress

  • Memory reliability lower bound; fixed-width overhead and wide-register amortization must be distinguished.[2]
  • Statistical decoding certification and estimator-dependent exact certificates; no universal fast optimal-decoding theorem.[3]
